> **1.3 — навыки по категориям и переживание перезагрузки страницы.**
> * **Библиотека `BW`** (Luau, `shared/src/bw-helpers.luau`) автоматически подставляется в каждый `execute_luau`,
>   который её использует: `BW.part / model / weldAll` (стройка), `BW.script / source / patch / scan / remote` (скрипты),
>   `BW.screen / ui` с `Corner / Stroke / Padding / List` (UI), `BW.particles(p, "fire"|"smoke"|"sparkles"|"magic"|"dust") / light` (VFX),
>   `BW.leaderstats / killPart` (геймплей), `BW.logs / tree / report / check / exists` (отладка и проверка).
>   Ошибки понятные (`BW: ...`), номера строк — из кода ИИ, а не библиотеки. Каждый вызов — одна точка Undo.
> * **Плейбуки по категориям** (`shared/src/playbooks.ts`): порядок работы, правила Roblox (Anchored, клиент/сервер,
>   RemoteEvent, ScreenGui в StarterGui, …), типичные ошибки и обязательный шаг **VERIFY**. Выбранная категория
>   попадает в инструкции модели. Это не дообучение весов модели — это инструменты + инструкции + проверка результата.
> * **F5 / перезагрузка вкладки** не останавливает агента: состояние сессии хранится в `chrome.storage.local`
>   (на 24 ч, для того же чата). После перезагрузки панель снова «Agent Active», журнал действий и этап восстановлены,
>   ожидающее подтверждение появляется снова, а вызов, который выполнялся в момент перезагрузки, **подхватывается
>   по id в мосте и не выполняется повторно**. Условие: мост (`start.bat`) не перезапускался.

Brickwire превращает обычный веб-чат (DeepSeek и Notion AI — beta; остальные — экспериментально) в агента,
который **реально** работает в открытом Roblox Studio: читает дерево игры и скрипты, создаёт объекты, UI, VFX,
правит код, запускает плейтест, читает ошибки и исправляет их.

```
AI-сайт ──► Provider Adapter ──► Agent Core ──► Brickwire Bridge ──► Roblox Studio MCP ──► Roblox Studio
(вкладка)    (расширение)        (расширение)    (127.0.0.1:47821)    (stdio, встроенный)    (ваш place)
```

* **Расширение** (Chrome/Edge, MV3) встраивает панель **ROBLOX AGENT** над полем ввода чата, отправляет
  модели инструкции и список инструментов, читает её ответы, находит блоки `ROBLOX_TOOL_CALL`,
  выполняет их через мост и вставляет `ROBLOX_TOOL_RESULT` обратно в чат.
* **Мост** (Node.js, без зависимостей) запускает встроенный MCP-сервер Roblox Studio (сам находит новейший `StudioMCP.exe`),
  ведёт реестр инструментов, проверяет аргументы, применяет политику безопасности, делает снапшоты,
  хранит память проекта и логи, показывает Dashboard.
* **Roblox Studio MCP** — официальный встроенный сервер Studio. Brickwire не модифицирует Studio и
  не использует плагины.

> Идея архитектуры «расширение + локальный мост + встроенный Studio MCP» вдохновлена проектом
> ZeroScript (GPL-3.0). Код Brickwire написан с нуля, код ZeroScript не использовался.

## Требования

* Windows 10/11 (или macOS) с **Roblox Studio** последней версии.
* **Node.js 20+** (install.bat поставит через winget, если его нет).
* Chrome, Edge, Brave или другой Chromium-браузер.

## Установка (шаги 1–8)

1. Распакуйте `release.zip` в папку, например `C:\Brickwire`.
2. Запустите **`install.bat`** — проверит Node.js, создаст `.env`, подскажет путь к расширению.
3. Откройте `chrome://extensions` (или `edge://extensions`), включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку `C:\Brickwire\extension\dist`.
5. В Roblox Studio: **Assistant → … → Manage MCP Servers → Enable Studio as MCP server**.
   Откройте place, с которым будете работать.
6. Запустите **`start.bat`** — стартует мост и откроется Dashboard `http://127.0.0.1:47821`.
   Статус должен стать **MCP_READY**.
7. Откройте сайт ИИ (например chatgpt.com) — над полем ввода появится панель **ROBLOX AGENT**.
8. Впишите задачу (или оставьте пустым) и нажмите **Start**. Агент отправит инструкции,
   изучит проект и начнёт работу. Опасные действия попросят подтверждения в панели.

Остановить мост — `stop.bat`. Обновить — `update.bat`.

## Обязательная проверка на вашей машине

В облачной среде разработки нет Roblox Studio (он не работает под Linux), поэтому финальный тест с
настоящей Studio нужно выполнить у вас. При запущенных Studio (с открытым place) и мосте:

```bat
node scripts\studio-e2e.mjs
```

Скрипт проходит цепочку **health → session → get_game_tree(Workspace) → create_part AgentTestPart →
проверка → delete (подтверждение через API) → проверка удаления** и печатает `RESULT: PASS/FAIL`.
Ручной чек-лист через чат — в [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md#ручной-чек-лист).

## Что проверено и как

| Что | Как проверено |
|---|---|
| Парсер, протокол, безопасность, Luau-сериализация, память, сессии | unit-тесты |
| MCP-клиент (stdio JSON-RPC, таймауты, переподключение, list_changed) | интеграционные тесты с mock MCP-сервером по stdio |
| Мост: реестр, валидация, approvals, снапшоты/откат, память, API | интеграционные тесты |
| Сгенерированный Luau всех композитных инструментов | выполняется в **настоящей Luau VM** со стабом Roblox API |
| Библиотека `BW`: по сценарию на каждую категорию (Build, Scripting, UI, VFX, Animation, Gameplay, Debug) | **настоящая Luau VM** со стабом Roblox API |
| Библиотека ресурсов: все 65 ресурсов собираются, все их скрипты компилируются, `BW.furnish` для 5 типов комнат | **настоящая Luau VM** со стабом + `luau-compile` |
| Вкладка Library: превью, поиск, «Build this» запускает агента с `BW.kit`, «Make something like it» во время работы | E2E в Chromium с расширением (мок-страница) |
| Скрипты, которые генерирует Animation (движение, двери, NPC, патруль, анимации игроков, инструменты) | компилируются и **выполняются** в Luau VM со стабом (Heartbeat, Animator, Humanoid, TweenService) |
| Перезагрузка страницы во время ожидающего подтверждения | E2E: F5 → агент восстановлен → подтверждение → ровно 5 выполнений, без дублей |
| Расширение + адаптеры 8 провайдеров + панель + agent loop | E2E в настоящем Chromium с загруженным расширением; страницы провайдеров — **моки DOM** на реальных доменах |
| Настоящая Roblox Studio и настоящие сайты ИИ | **не проверено в sandbox** — `scripts/studio-e2e.mjs` и чек-лист для вас |

Статус провайдеров — [docs/PROVIDERS.md](docs/PROVIDERS.md). Вёрстка сайтов меняется; адаптеры
используют несколько стратегий поиска поля ввода/кнопки и семантический fallback, но после
обновления сайта селекторы может понадобиться поправить (`extension/src/adapters/providers.ts`).

## Режимы безопасности

* **auto** (по умолчанию) — чтение и обычные изменения выполняются сразу, разрушительные
  (удаление, перезапись скриптов, опасный Luau) требуют подтверждения.
* **approval** — подтверждение каждого изменения.
* **safe** — только чтение.

Перед изменениями мост делает снапшот затрагиваемых объектов в `ServerStorage.__BrickwireSnapshots`;
откат — инструмент `restore_snapshot` или кнопка в Dashboard. Все изменения также попадают в
Undo-историю Studio (ChangeHistoryService waypoints).
