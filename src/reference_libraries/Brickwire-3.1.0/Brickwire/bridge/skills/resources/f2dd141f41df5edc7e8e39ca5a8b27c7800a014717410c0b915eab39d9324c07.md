# Check-UI Clean Roblox

Source: https://github.com/TemporaryLooker22/Check-UI-Clean-Roblox (copied 2026-10-09, commit of 2026-10-05).

The project's README states: "Distributed under the MIT License. Free to use, adapt, and distribute in any
personal or commercial Roblox experience." The repository has no LICENSE file and does not say who drew the
icons; the icon images are Roblox assets uploaded by the repository's author.

Files here are unmodified copies: CheckUITheme.luau, CheckUIComponents.luau, CheckUIIcons.luau,
CheckUIController.luau, SKILL.md, DESIGN_SYSTEM.md. Lurong's agent reads them through
`agent-instructions/checkui.md`, the `find_icon` tool and the `install_checkui` tool (studio-agent.cjs).
