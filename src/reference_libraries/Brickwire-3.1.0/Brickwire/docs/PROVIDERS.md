## Статусы (честно)

* **DeepSeek — beta.** Единственный провайдер с отдельным адаптером, проверенным на реалистичной реплике
  живого DOM DeepSeek (общая кнопка Send/Stop без aria-label, фаза рассуждения, паузы стриминга,
  пересоздание DOM). На живом сайте нужно подтверждение пользователем.
* **Остальные — experimental.** Работают через общий DOM-адаптер и проверены только на упрощённых
  mock-страницах. Не считайте их рабочими, пока не проверите на живом сайте.

## Что значит «beta» (старое описание)

Адаптер реализован и проходит E2E в настоящем Chromium с загруженным расширением на **mock-страницах**,
которые воспроизводят DOM-структуру сайта (поле ввода, кнопки отправки/остановки, разметка ответов,
стриминг) и открываются по реальным доменам. На **живых** сайтах в sandbox адаптеры не проверялись
(нужны аккаунты и вход). Проверьте по чек-листу из TROUBLESHOOTING.md; если сайт обновил вёрстку,
пришлите HTML поля ввода — селекторы правятся в `extension/src/adapters/providers.ts`.

Устойчивость к изменениям вёрстки: у каждого адаптера несколько селекторов на элемент, затем
семантический поиск (видимое textarea/contenteditable внизу страницы, кнопка с aria-label
«Send/Отправить»), отправка подтверждается (поле очистилось / появилось новое сообщение), иначе
пробуется следующая стратегия. Панель монтируется заново, если SPA перерисовала страницу.

## Метки доставки и универсальное чтение ответов (1.5)

Каждое сообщение Brickwire заканчивается меткой `[bw:xxxxx]` (5 символов). Она даёт две вещи:

1. **Подтверждение доставки.** После отправки сторож проверяет, что метка появилась в ленте чата (не в поле
   ввода), или начался ответ. Если нет за ~7 с — сообщение отправляется снова (до 4 попыток), потом пауза и
   уведомление в панели. Через 150 с без ответа — предупреждение.
2. **Чтение ответа на любой вёрстке.** Ответ = текст, который сайт отрисовал после нашей последней метки,
   до поля ввода (панель, поля ввода и элементы интерфейса короче 24 символов отбрасываются). Сообщения, которые
   вы пишете сами (Enter / кнопка отправки), запоминаются как границы, поэтому старый ответ не смешивается с новым.
   Для Notion, Grok, Mistral, Perplexity, Copilot, Poe и своих сайтов это основной способ; для остальных —
   запасной, если селекторы перестали находить ответы.

Метки хранятся в `sessionStorage` вкладки (переживают F5).

## Notion AI — полноценный провайдер (1.5)

* **Поле ввода:** выбирается среди видимых contenteditable/textarea, которые **не** внутри страницы
  (`.notion-page-content`, `[data-block-id]`, топбар, сайдбар). Оценка: подпись «Ask AI / Спросите / anything / message»,
  контейнер-диалог/боковая панель, маршрут `/chat`, положение внизу экрана. Вне `/chat` принимается только явно
  «ИИ-шное» поле — редактор страницы не трогается никогда.
* **Фиксация поля (3.0):** найденное поле запоминается, пока оно в DOM (placeholder пропадает, когда в поле есть текст).
* **Кнопка отправки:** по aria-label (Send/Submit/Отправить) или крайняя правая иконка в блоке ввода (до 12 уровней вверх);
  кнопки вложений, upload, упоминаний и выбора модели исключены; иначе Enter (перед ним закрываются всплывающие меню).
* **Генерация:** Stop по подписи, `<rect>` или квадратному пути в блоке ввода, либо рост текста (порог тишины 6 с).
  Ожидание занятости до 120 с, повторная доставка через 25 с, панель плавающая, keep-awake выключен.
* **Notion mode в инструкциях:** Studio — только через теги Brickwire; собственные действия Notion AI (страницы,
  базы, поиск) не трогают Studio и не заменяют вызовы. ТЗ из страниц (@страница) превращается в план в числах;
  по просьбе — чек-лист задач; размеры/цвета/цены берутся из ТЗ.
* **Dev log** (переключатель в панели, только на Notion): после каждого проверенного DONE — короткая запись на
  странице «Roblox Dev Log»: дата, что изменено, пути в Studio, как проверено.
* **Честно:** проверено на реплике (редактор-приманка + поле чата без стабильных классов + иконка-кнопка),
  не на живом Notion. Если что-то не так — нажмите **Site check** в панели и пришлите отчёт (он копируется
  в буфер) + скриншот.

## Свои сайты

Настройки расширения → **Other AI sites** → хост (`chat.example.com`), имя, при необходимости селекторы поля,
кнопок Send/Stop (альтернативы через `||`). Браузер попросит разрешение только на этот сайт; расширение
регистрирует на нём content script. Ответы читаются по меткам.
